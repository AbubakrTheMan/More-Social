# MORE — More Than Social
First responsive front-end prototype for MORE.

## Deploy
Upload `index.html` to the root of your GitHub repository. In Vercel, choose **Add New → Project**, import the repository, select **Other** as the framework preset if asked, then deploy.

## Scope
This is a static front-end prototype. Demo posts and counts are sample content. Authentication, database, media uploads, messaging, notifications and cross-user interactions are not connected yet.
